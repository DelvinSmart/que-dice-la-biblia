# SBLGNT · Nuevo Testamento griego

Texto griego del **SBL Greek New Testament (SBLGNT)**, copyright 2010 Society of Biblical Literature y Logos Bible Software, con licencia [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/) (ver `LICENSE`).

- Origen: https://github.com/Faithlife/SBLGNT (`data/sblgnt/text`, commit d7f35ad, versión 1.2).
- Cambios: un archivo JSON por libro (`{"capítulo": {"versículo": "texto"}}`, con el código de Bible.com en el nombre) y **sin los signos del aparato crítico** (⸀ ⸁ ⸂ ⸃ ⸄ ⸅). Las palabras no se cambiaron. Los corchetes [ ] y ⟦ ⟧ del texto se dejaron.
- Lo usa el bloque "Griego" del panel: escoges la referencia y los versículos se llenan solos desde aquí.
